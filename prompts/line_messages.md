# LINE 文面テンプレート（LLM で生成せず、変数だけ差し込む）

## greeting（友だち追加時）
```
友だち追加ありがとうございます。
あなたの誕生日だけの開運待ち受けをお届けします。

誕生日を4けたで送ってください。
例：3月15日生まれなら「0315」
（生まれた年は必要ありません）

※画像はAIで作成しています。占い・おまじないとして楽しんでください。
プライバシーポリシー：{PRIVACY_POLICY_URL}
```

## birthday_reply（A群）
```
{M}月{D}日生まれのあなたの守護カラーは「{color_name}」。
モチーフは{motif}です。保存して待ち受けにしてね。
```
（直後に画像メッセージ）

## common_reply（B群）
```
{M}月{D}日生まれのあなたへ、開運待ち受けをお届けします。
保存して待ち受けにしてね。
```
（直後に共通画像。A群と文面の長さ・トーンを揃える）

## daily_word（「ひと言」を受け取ったとき。A/B 共通）
```
今日のひと言
「{affirmation}」
※占い・おまじないとして楽しんでください。
```

## parse_error
```
うまく読み取れませんでした。
誕生日を4けたの数字で送ってください（例：0315）。
```

## weekly_push（「開運日」を受け取ったときの返信にも使う。docs/03 §5-0）
```
今週の開運日：{date_label}（{type_label}）
この日の待ち受けをどうぞ。
※占い・おまじないとして楽しんでください。
```
（直後に開運日版の画像）

## pack_offer（友だち300人到達後）
```
これまでの待ち受けをまとめた高画質パックを用意しました。
{PACK_URL}
```
（A/B で PACK_URL を分ける。docs/09 #2）
