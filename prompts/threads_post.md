# 本文生成：Threads 本投稿（画像1枚＋本文）

## 入力
- theme: birthday | kaiunbi | affirmation
- date_label: 例「3月15日生まれ」「10月10日 一粒万倍日」「今日のアファメーション」
- affirmation: theme=affirmation のときの言葉（`data/affirmations.yaml`）
- color_name, motif, keyword
- recent_texts: 直近90日の Threads 本文

## 指示
- 150〜300字（上限500字）。次の順で書く：
  1. 用途（例：「今日3月15日生まれさんの守護カラー待ち受け」）
  2. 守護カラー名とモチーフの一言
  3. 呼びかけ：「あなたの誕生日も4けたでリプしてね。守護カラーをお返事します（例：0315）」
  4. 導線：「誕生日だけの待ち受けはプロフィールのリンクのLINEで」
  5. 定型文：「※画像はAIで作成しています／占い・おまじないとして楽しんでください」
- 外部リンク・ハッシュタグは入れない（トピックタグを使う場合は1個まで、人が指定したときのみ）。
- 効果を断定しない、不安をあおらない、健康効果を書かない（docs/08 の NG ワード）。
- recent_texts と同じ言い回しを避ける。呼びかけ（3）と定型文（5）の文言は固定でよい。
- 出力は本文のみ。
