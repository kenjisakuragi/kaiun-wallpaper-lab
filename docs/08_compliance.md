# 08 表現・法務・プラットフォーム規約ガイドライン

これは実装上の安全側ルールであり、法的助言ではない。公開前に人が確認する。

## 1. 表現ルール（投稿文・返信文・動画テロップ・LINE文面共通）
- 効果を断定しない：「必ず」「確実に」「絶対」「即効」「〜が叶う」「金運が上がる（断定形）」は使わない。「〜と言われています」「お守りがわりに」などにする。
- 不安をあおらない：「このままだと不幸に」「見ないと運気が下がる」「最終警告」「すぐ削除」などは使わない。
- 健康・医療の効果を書かない。
- 限定・希少性の偽装をしない。
- 守護カラー・モチーフはこのプロジェクト独自の設定であり、伝統・学説・宗教的権威を名乗らない。
- 娯楽である旨を、投稿文末尾とLINEのあいさつ文に入れる。

## 2. NG ワード
`data/ng_words.txt` に1行1語（`re:` 接頭辞で正規表現）。検査は全角半角・ひらがなカタカナの揺れを正規化してから行う。人が随時追加する。

**2026-10-04 決定（`docs/09` #16）：NG ワード検査で送信を止めない。** 動作は `NG_WORD_MODE` で切り替える。
- `off`：検査しない
- `warn`（初期値）：検査して該当語をログに記録するが、送る（数字を見るため）
- `block`：該当したら送らない（元の運用）
§1 の表現ルールは、生成プロンプトの指示として引き続き使う。

## 3. 法令上の注意（要点）
- 消費者契約法：霊感など合理的に実証困難な能力による知見で不安をあおり、契約で確実に回避できると告げて契約させた場合は取消しの対象。有料案内では不安訴求を一切しない。
- 景品表示法：効果の誇大表示をしない。第三者に投稿を依頼する場合は広告である旨を明示（ステルスマーケティング規制）。
- 特定商取引法：note で販売する場合は note の販売機能の表示要件に従う。
- 個人情報：
  - LINE：取得するのは userId（ハッシュ・暗号化して保存）と誕生月日のみ。生年は求めない。
  - Threads：リプの本文・月日・生のユーザー名は保存しない（`docs/05` の threads_replies）。
  - プライバシーポリシーを LINE のあいさつ文と Threads・Instagram のプロフィールからリンクする（文面は人が用意）。

## 4. AI 生成の開示
- 投稿文末尾に「※画像はAIで作成しています」。
- Threads・Instagram で AI ラベルを API 指定できるか確認（`docs/04`）。できなければ投稿後にアプリで確認する運用にする。
- Threads の自動返信が AI によるものであることを、プロフィールに明記する（例：「誕生日リプへのお返事は自動で送っています」）。

## 5. 自動化の範囲（スパム判定を避けるため）
- 自動で行う能動的な行為は「自分の投稿への直接のリプへの返信」だけ。他人の投稿へのリプ・メンション・いいね・フォロー・リポストは自動化しない。
- 自動返信は日次上限（初期50件）を守り、返信文は直近200件と類似しないものにする。リンク・ハッシュタグを入れない。LINE への誘導文は3回に1回まで。
- 同一または高類似の投稿の大量複製をしない。複数アカウントで同一内容を投稿しない。
- 相互フォロー、懸賞は行わない。
