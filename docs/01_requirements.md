### 1-2. Threads・Instagram に関する事実
- micane（占いメディア）は Instagram で毎日カルーセル投稿→DM誘導、Threads も運用。Instagram フォロワー16.5万はプロフィールの自己申告。
- 事業譲渡サイトの出品（自己申告）：Instagram・Threads 5アカウント合計約10万フォロワー、LINE有効リスト15,000、投稿作成は外注、LINE は AI 自動返信。別案件：顔出しなし Instagram 5,886フォロワー、ChatGPT＋Canva で1投稿10分、LINE 1,500人。
- Threads はリプライ（会話）を重視して配信を広げるとされる（二次情報）。
- **未検証**：待ち受け配布型が Threads・Instagram で TikTok と同じように伸びるかは、確認できた事例がない。本実験はその検証も兼ねる。

## 2. 実験の問い
1. 待ち受け配布型を Threads・Instagram で行うと、LINE リストは月に何人増えるか。媒体ごとに違うか。
2. Threads で「誕生日をリプしてくれたら守護カラーを返す」仕組みは、リプライ数と LINE への遷移を増やすか。
3. 「誕生日ごとの専用画像（A）」は「全員共通の高画質版（B）」より、入力完了率・継続率（ブロックされない率）・購入率を上げるか。※前例のない仮説。
4. LINE リストから、バックエンド商品の AI チャット占い（別プロジェクト）に何%が登録・課金し、1人あたりいくらの限界利益が残るか（2026-10-06 変更。壁紙パックは補助の選択肢）。

## 3. スコープ
### やる
- 366日分（2/29含む）の誕生日別画像、共通版（B群用）、開運日版、アファメーション版の生成
- 題材に「引き寄せ（アファメーション）」を加える（2026-10-04 採用、調査の B 案）
- Threads：画像付き投稿の自動公開、自分の投稿へのリプに対する自動返信（上限・承認モード付き）
- Instagram：15秒の縦動画（リール）の自動合成と自動公開
- プロフィールリンク用のリダイレクト（媒体別のクリック計測 → LINE 友だち追加）
- LINE：月日を送ると画像が返る自動返信、A/B割り当て、週1回の開運日配信、キーワードで「今日のひと言」を返す自動返信（応答メッセージなので通数に数えない）
- 指標取得と週次レポート
- LINE から AI チャット占いへの送客（リンクと計測）。バックエンド商品は AI チャット占い（2026-10-06 決定）
- 利益の点検（`pnpm profit:audit`）：導線ごとに広告費控除後の限界利益を再計算できるようにする
- note 出品用の壁紙パック書き出し（出品は手動。補助の選択肢）

### やらない
- TikTok・X・note への自動投稿（TikTok は Threads・Instagram の結果を見て判断）
- 有料広告、懸賞、相互フォロー、フォロー・いいね・リポストの自動化
- 自分の投稿以外へのリプ・メンション
- 生年・氏名・メールアドレスなどの収集
- AI占いチャット本体（別プロジェクト）

## 4. 実験設計
- **投稿量**：Threads・Instagram とも1日1本（必要なら2本）。判断は各媒体100本到達時。それまでは数字が悪くても止めず、画像テイストと文面の調整のみ行う。
- **題材**：(a) 誕生日別（「○月○日生まれの守護カラー」）、(b) 開運日（一粒万倍日・天赦日など）、(c) アファメーション（引き寄せ系の短い言葉＋待ち受け）。比率は (a):(b):(c) = 2:1:1 を仮の初期値とする（`docs/09` #15）。
- **LINE の継続価値**：画像を1回受け取って終わりにしないため、キーワード（例：「ひと言」）を送ると、その日のアファメーションを返す。Reply API で返すので通数に数えない。A/B 両群に同じ内容を返し、A/B の差は画像だけに保つ。
- **Threads の誕生日リプ返信**：投稿文で「誕生日を4けたでリプしてね、守護カラーをお返事します」と呼びかけ、リプに守護カラー名とキーワードを文章で返す（画像とリンクは返信に含めない。画像はプロフィールのリンクから LINE で受け取る）。
- **A/B**：LINE で月日を受け取ったユーザーを A/B に割り当てる（`docs/02` §4）。A：その月日専用の画像／B：全員共通の高画質版。
- **収益化テスト**（2026-10-06 変更）：AI チャット占いの公開後、LINE で AI チャットの体験（登録特典つき）を案内し、登録・課金・継続と、無料体験の AI 原価を測る。壁紙パックは AI チャットが使えない間の補助の選択肢。

## 5. KPI（定義は `docs/06_kpi_and_reporting.md`）
| KPI | 比較用の実数 | 100本時点の判断 |
| --- | --- | --- |
| 月間 LINE 友だち純増 | 約78人/月（ハナプラ平均、TikTok） | 上回れば継続・拡大 |
| 媒体別のリンククリック数 | 前例なし | 媒体ごとの継続判断に使う |
| Threads：リプ率（リプ÷表示）・誕生日リプ数 | 前例なし | 実測値を記録 |
| Instagram：保存率（保存÷再生） | 参考：TikTok の代表動画で 0.2% / 0.51% / 0.96% | 媒体が違うため参考値のみ |
| A/B 差（入力完了率・30日ブロック率） | 前例なし | 各群100人以上で差がなければ個別化を廃止 |
| note 購入率 | 前例なし | 実測値を記録 |

注意：比較用の実数はいずれも 1〜3件の代表値で、しかも TikTok のもの。統計的な基準でも、Threads・Instagram の基準でもない。

## 6. 非機能要件
- 月額ランニングコスト：LINE のプッシュ通数が月200通以内の間は、画像生成の初期費用を除きほぼ0円。超えたら LINE ライトプラン（月5,000円・5,000通）への切り替えを人が判断する。
- 運用工数：週1時間以内（Threads 自動返信の承認、画像確認、レポート確認）。自動返信を承認モードで運用する初期2週間は1日10分程度を見込む。
- 障害時：投稿が1日欠けても実験は継続可能。二重投稿・二重返信は不可。
