# 06 KPI と週次レポート

## 1. 指標の定義
| 指標 | 定義 | データ源 |
| --- | --- | --- |
| 投稿本数（累計） | 媒体別に status=published の本数 | posts |
| Threads リプ率 | 投稿ごとの replies ÷ views。週の中央値 | post_metrics |
| 誕生日リプ数 | `threads_replies` の parsed_ok=1 の件数（週） | threads_replies |
| 自動返信の送信数・上限到達日数 | status=sent の件数、capped が出た日数 | threads_replies |
| Instagram 保存率 | 投稿ごとの saves ÷ views。週の中央値 | post_metrics |
| 媒体別リンククリック | `link_clicks` の媒体別件数（週） | link_clicks |
| LINE 友だち純増 | 期間内 follow 数 − unfollow 数 | users |
| 入力完了率（A/B別） | 友だち追加から7日以内に月日を送った割合 | users |
| 7日・30日ブロック率（A/B別） | 観察期間を満了したユーザーのうち、その期間内に unfollow した割合 | users |
| 今日のひと言の利用（A/B別） | `daily_word_reply` の件数と、利用した人数（週） | deliveries |
| NG ワード該当数 | `NG_WORD_MODE=warn` で記録された該当件数（週） | ログ |
| プッシュ通数（月） | `deliveries.counted=1` の当月合計 | deliveries |
| 壁紙パック購入率 | 購入数 ÷ 案内を送った人数 | purchases, deliveries |
| 画像生成コスト累計 | `images.cost_usd` の合計 | images |

## 2. 比較基準（参考値。統計的基準でも、Threads・Instagram の基準でもない）
- 月間 LINE 純増：ハナプラ（TikTok）平均 約78人/月（3,968 ÷ 約51か月、自己申告値からの推計）
- 保存率（TikTok の代表動画1本ずつ）：0.2% / 0.51% / 0.96%
- Threads のリプ率・クリック数：比較できる実数なし。本実験の最初の4週を基準値にする。

## 3. A/B の比較方法
- 群ごとの人数・入力完了率・ブロック率を並べ、割合の差に 95% 信頼区間（Wilson 法）を付ける。
- 各群 100人未満の間は「判断不能」と明記する。
- 群の人数比が 45:55 を外れたら警告を出す。

## 4. 週次レポート（`out/reports/YYYY-Www.md`）
数字中心で、所感は書かない。
1. 媒体別の今週の投稿本数と累計（100本までの残り）
2. Threads：表示・リプ率中央値・誕生日リプ数・自動返信の送信数・上限到達日数（前週比）
3. Instagram：再生・保存率中央値（前週比）
4. 媒体別リンククリックと LINE 友だち純増
5. LINE：累計、入力完了率、ブロック率（A/B別、信頼区間付き）
6. 今月のプッシュ通数とプラン上限までの残り
7. 画像生成コスト累計
8. 失敗した投稿・返信の一覧
9. 判断ルールへの該当

## 7. 利益の指標（2026-10-06 導入、`pnpm profit:audit`）
| 指標 | 定義 |
| --- | --- |
| AI チャット送客 | LINE からの `/go/chat` クリック数、AI チャット側で流入元 ref が付いた登録数・課金者数・課金額（AI チャット側のデータ。受け取り方は docs/09 #33） |
| 無料体験の AI 原価 | 登録者1人が無料で使った通数 × 1通あたり AI 原価 |
| 広告費控除後の限界利益 | 返金後売上 − 決済手数料 − AI 原価（有料分＋無料体験分）− 広告費 |
| LINE 友だち1人あたり限界利益 | 上の限界利益 ÷ 同期間の LINE 友だち増。獲得単価（広告を使う場合）の上限の目安 |
| 人の作業時間 | 指示・確認・修正・問い合わせ対応を含む時間（AI が速く処理した時間とは別に記録） |
- 測定できない部分は「未確認」のまま残し、推測で埋めない。追えない購入を特定の投稿の成果にしない。

## 6. 評価ループ（2026-10-04 追加、`docs/09` #28）
- 記録：投稿ごとに、何を変えたか（`prompt_version`・`hook_type`・`style_version`・`post_time`・題材・NG ワードの該当語 `ng_hits`）を `posts` に残す。
- 計測：投稿から24時間・72時間・7日の時点で指標を取る（`post_metrics` に同じ投稿を複数回記録）。比較は同じ経過時間どうしで行う。
- 集計：週次レポートに、題材別（誕生日・開運日・アファメーション）、変更点別、NG 該当あり・なし別の中央値と件数を出す。各区分5件未満は「判断不能」。
- 変更案：レポート末尾に「来週の変更案」を出す。自動では反映せず、承認したらプロンプト等のバージョンを上げる（委任中は Claude Code が判断して記録してよい）。

## 5. 判断ルール（各媒体100本時点、人が判断）
| 条件 | アクション |
| --- | --- |
| 月間純増 > 78人 | 継続・拡大（企画1の星座別アカウントへの送客テストへ） |
| 媒体のクリックが他媒体の1/3未満 | その媒体の投稿形式を変えるか停止を検討 |
| Threads の誕生日リプが週10件未満 | 呼びかけ文と投稿時刻を変更 |
| 自動返信が上限に達する日が週3日以上 | 上限を上げるか、返信対象を絞る（例：投稿後24時間以内のみ） |
| Instagram 保存率中央値 < 0.2% | 画像テイストを変更 |
| A/B に有意差なし（各群100人以上） | 個別化を廃止し、共通版に一本化 |
| プッシュ通数が上限の80% | プラン変更か配信頻度の削減を判断 |
